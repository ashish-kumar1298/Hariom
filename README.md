# Hari Om Medical Store

A 24/7 pharmacy website designed for passengers and local customers near Varanasi Junction Railway Station.

## 🚀 Features

- 24/7 Pharmacy Information
- Medicine Availability Search
- AI Pharmacy Assistant
- Travel Health Guidance
- Prescription Upload
- OTC Medicine Pack
- Quick Order & Pickup
- WhatsApp Ordering
- Store Location & Contact Information
- Responsive Website Design

## 🤖 AI Pharmacy Assistant

The website includes a client-side AI-style pharmacy assistant that provides curated travel-health guidance for common situations such as:

- Travel sickness
- Fever & headache
- Acidity
- Diarrhea
- Dehydration
- Cold & allergy
- Toothache

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
- Web Speech API
